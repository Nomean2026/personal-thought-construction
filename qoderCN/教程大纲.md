# 自我改善教程 · 大纲规划文档（Spec）

> 本文档是全套教程的总体规划（Spec），先于各章节内容完成。
> 教程定位：从专业心理学与辩证唯物主义双重视角，分析"你"这个系统的成因与运行机制，
> 并以"理解道理 → 剖析原因 → 落实方法"的循序渐进逻辑，带你完成内在统一与持续改变。

---

## 一、教程定位与教学逻辑

### 1.1 教程目标
不是给你一堆"道理"，而是让你：
1. **看清楚**自己这套"程序"是怎么写出来的（成因）
2. **看懂**它现在为什么这样运行（机制）
3. **能动手**改写它（实践方法）
4. **能持续**维护它（生活系统）

### 1.2 教学三段式（每章统一遵循）
```
① 理解道理（What） → 这一章讲的现象与原理是什么
② 剖析原因（Why）  → 它在你身上为什么这样形成、这样强化
③ 落实方法（How）  → 切实、简单、可执行的改变步骤
```

### 1.3 理论基底
- **辩证唯物主义**：客观环境是主要的，主观能动性是启动器；事物是发展变化的、相互影响的。
- **心理学**：依恋理论、原生家庭理论、神经可塑性、认知行为疗法（CBT）、接纳承诺疗法（ACT）、习惯回路、自我决定理论。
- **实践框架**：学—抄—做三阶段（神经重塑 = 学习）。

## 三、各章详细内容规划

### 第一章 总论：成因全方位剖析
**目的**：先把"你"作为一个系统讲清楚，后续每章都是在改这个系统的某个模块。

- **(a) 成长过程的成因**
  - 原生家庭的反馈模式（不清晰、矛盾、负向）
  - 母亲的行为模板：抗拒沟通 + 信守"承诺"到自我伤害 + 事后抱怨
  - 安全型 vs 焦虑型依恋的形成
  - 模仿—实践—内化的代际传递通路
- **(b) 性格本身的成因**
  - 高敏感气质（HSP）特质
  - 内向 + 回避型应对倾向
  - 完美主义 + 非黑即白认知
  - 控制感需求与不确定性的冲突
- **(c) 生理上的因素成因**
  - 神经可塑性：旧通路被反复强化
  - 杏仁核敏感、威胁检测系统过度激活
  - 前额叶 vs 边缘系统的拉锯（理性知道，情绪抗拒）
  - 精力/睡眠/饮食对执行功能的直接影响
- **(d) 现有的理论和技巧、方式方法**
  - 依恋理论（四类型）
  - 认知行为疗法（ABC模型、认知重构）
  - 接纳承诺疗法（认知解离、价值行动）
  - 习惯回路（提示—行为—奖赏）
  - 神经可塑性原理
  - 自我决定理论（自主、胜任、关系）
  - 辩证唯物：客观环境重塑主观

### 第二章 沟通抗拒与权益维护
**核心案例**：公租房空调报修拖延、与领导沟通回避、投简历拖延、教务处拖延半年。

- 现象梳理：从公租房空调到领导请假到简历，一条"回避链"
- 成因：威胁检测 + 习得性无助 + 自我效能感低 + 负向预期
- 机制：回避带来短期缓解 → 强化回避 → 问题积累 → 更难行动
- 方法：
  - 最小行动法（5分钟、一句话）
  - 脚本化沟通（提前写好话术，降低决策消耗）
  - "想到就干"的触发器设计
  - 权益维护的阶梯（公租房电话→市长热线的真实路径）
  - 正反馈记录本

### 第三章 行动瘫痪与间歇性动机
**核心现象**：睡前放松时想得清楚，醒来又抗拒；状态差时更无法行动。

- 现象：状态依赖性决策，"两个自己"的拉锯
- 成因：前额叶（理性）与边缘系统（情绪）在不同生理状态下的力量对比
- 机制：放松状态→前额叶主导→清晰；清醒压力状态→杏仁核激活→回避
- 方法：
  - 抓住"清醒时刻"立刻固化（写下、录音、预约）
  - 行动门槛降到极低（2分钟法则）
  - 状态管理优先于任务管理
  - "如果—那么"预设计划
  - 允许反复，但缩短反复周期

### 第四章 原生家庭代际遗传
**核心案例**：母亲江边驿站、老家代课、攒塑料袋、洗澡水洗衣服、节俭克己。

- 现象：你的模式与母亲高度同构（回避+信守+抱怨+负向）
- 成因：模仿—实践—内化的神经通路塑造
- 机制：基因生理=基本反馈器；原生家庭=基本程序；后续环境=程序修正
- 关键认知：
  - 代际遗传 = 一直参考的模板是身边人
  - 改变 = 需要新模板（看别人怎么做）+ 自己实践
  - 神经重塑 = 学习 = 学—抄—做
- 方法：
  - 寻找并接触"安全型"模板（人、关系、内容）
  - 主动创造新环境（你的买花改变就是实证）
  - 小范围实践新通路并记录
  - 与母亲分开居住（减少旧通路激活）

### 第五章 决策疲劳与完美主义
**核心案例**：买衣服纠结几小时、Edge浏览器装4个版本、AI编程软件挨个学。

- 现象：在工具/购物/软件上反复比较，精力被掏空
- 成因：完美主义 + 控制感需求 + 原生家庭节俭习惯 + 不确定性的不耐受
- 机制：选择本身消耗执行功能；"最优解"幻觉驱动无限比较；每一次比较都是一次小内耗
- 方法：
  - "足够好"标准（满意化原则 vs 最大化原则）
  - 决策时间盒（限定时长，到点就定）
  - 工具锁定清单（一个领域只用一个工具）
  - 把"折腾工具"的时间划入"想做"而非"应做"
  - 识别"折腾"是逃避正事的信号

### 第六章 敏感气质与自主性缺失
**核心案例**：语音输入被打扰就不想弄、图书馆注意力被影响、包放旁边座位担心别人。

- 现象：高敏感 + 易受外界/他人影响
- 成因：HSP生理基础 + 成长环境缺少自主性培养 + 过度在意他人
- 机制：外部刺激→注意力强制转移→情绪扰动→行动中断
- 方法：
  - 区分"感受"与"反应"（敏感可以，但不必跟着反应）
  - 物理边界（耳机、固定座位、勿扰时段）
  - 自主性小练习（每天一个"我决定"）
  - 注意力锚定练习

### 第七章 与母亲的关系
**核心现象**：本能反感、道理懂但现实反应隔阂、习得性无助。

- 现象：睡前能理解她，现实里听到第二句话就反感
- 成因：长期负面交互形成的条件性厌恶反应 + 现实琐事持续触发
- 机制：理想认知（前额叶）vs 本能反应（杏仁核）的拉锯；琐事是高频触发器
- 关键认知：不能靠"一直保持睡前状态"来解决问题
- 方法：
  - 接纳本能反应的存在（不与本能对抗）
  - 物理分离优先（分开居住是根本解）
  - 降低交互频率与强度（结构化沟通）
  - 把"理解"变成具体的小动作而非大状态
  - 不要求自己"变好"，只要求"少恶化"

### 第八章 负向思维与认知重构
**核心案例**：换工作想负面结果就想终结、家庭氛围偏负向、危机意识过强。

- 现象：总是先看到不好和危险的点
- 成因：原生家庭负向模板 + 杏仁核威胁检测敏感 + 确认偏误
- 机制：负向预期→焦虑→回避/终结→没有新经验→负向预期被"验证"
- 关键认知：安全型家庭的清晰反馈机制是大脑的刚需
- 方法：
  - ABC认知重构（事件—信念—结果，质疑信念）
  - "最坏—最好—最可能"三栏思考
  - 建立确定性反馈的小任务（清晰目标+清晰反馈）
  - 领导反复修改无答案 = 她把焦虑传给你，识别并隔离

### 第九章 生活系统重构
**核心**：把前面所有改变装进一个可持续运行的日常系统。

- 任务三分法：想做 / 认为要做 / 不得不做（第三种越少越好）
- 每日时间结构：上午做"认为要做"；晚上留时间给"想做"和社交
- 饮食：少辛辣、补蛋白质（中午下午）、增加蔬菜、记录反馈
- 睡眠：23-24℃、60-70%湿度、控制大脑兴奋
- 精力管理：减少大脑矛盾与纠结的消耗
- 行动正反馈：记录每一次"想到就干"的胜利（如已打公租房电话）
- 核心三条：与母亲分开居住 / 接纳敏感人格 / 尽快行动想干的事

## 六、教学总原则
> 你的核心洞察是对的：**最管用的是行动，只有通过一次次行动的正向反馈才能客观改善，但也可能反复。**
> 本教程的所有方法，都服务于一个目标：**降低行动门槛，增加正反馈，接纳反复，持续向前。**
