## 9.1 为什么需要"系统"而不是"意志"

前八章给你的是认知和工具。但工具散落着用，会被生活的惯性冲散——你状态好时能用，状态差时就忘了。**系统的作用，是让正确的事变成默认动作，不依赖你的状态**。

你的核心洞察已经说明了这点：
> "最管用的是行动，只有通过一次次的这种行动的正向反馈，才能客观改善，但也有可能反复。"

系统的目的就是：**降低行动门槛、固定正反馈、容纳反复**。

## 9.2 任务三分法（你的原创，完全正确）

你提出的三分法非常科学，我帮你系统化：

| 类型 | 定义 | 例子 | 安排原则 |
|------|------|------|----------|
| **想做** | 自然萌生的想法 | 试驾一辆车、打球、旅游 | 每天必留时间，哪怕30分钟 |
| **认为要做** | 理性判断该做 | 学大模型、跑通代码、投简历 | 每天固定时段集中做 |
| **不得不做** | 不想做但必须 | 请假、打电话、回领导消息 | 越少越好；尽快做完解脱 |

**关键原则**：
1. 第三种（不得不做）越少越好——能委托、能简化、能预办的都提前办
2. 第二种（认为要做）每天安排固定时间，给掌控感
3. **第一种（想做）每天必留时间**——这是生活平衡的命脉。你之前把自己逼到图书馆学习，砍掉的就是这一块，结果整个系统崩溃

**为什么"想做"最重要**：自我决定理论（SDT）的"自主感"主要来自做"我想做"的事。长期只做"应该"和"不得不"，自主感枯竭，动力崩溃。你女朋友让你买花那段之所以改变你，部分原因就是它属于"想做"被允许了。

## 9.3 每日时间结构（建议模板，可调）

基于你的实际情况（术后休养、想学习、想换工作、状态不稳定）：

```
07:00-08:00  起床、缓慢启动、吃早餐（蛋白质+蔬菜）
08:00-11:30  【认为要做】时段：学习/投简历/跑代码
              （状态最好的时间给最难的事）
11:30-13:00  午餐（蛋白质+蔬菜）+ 短休
13:00-15:00  【认为要做】续：或处理"不得不做"（如发消息）
15:00-16:00  散步/恢复（高敏感需要低刺激时间）
16:00-18:00  灵活：学习/杂事/小任务（清晰反馈类）
18:00-19:30  晚餐 + 与母亲简短互动（结构化时段）
19:30-21:30  【想做】时段：朋友/兴趣/试驾/放松
              （这是命脉，不可砍）
21:30-22:30  准备睡眠：降温到23-24℃、湿度60-70%
              不刷折腾类内容
22:30-23:00  睡前：写正反馈记录、预设明天的"如果—那么"
23:00         睡觉
```

**这不是死规定，是脚手架**。状态差时砍掉"认为要做"，保留"想做"和睡眠；状态好时多做一些。但骨架在，你就不会完全迷失。

## 9.4 饮食（你已在实践，继续+优化）

你前天的研究方向对，继续执行并补充：

2. **补充蛋白质**：中午和下午摄入偏少 → 重点补这两顿

**为什么饮食是改变的前提**：前额叶是全身最耗能脑区之一。蛋白质不足→神经递质合成不足→前额叶功能下降→杏仁核相对增强→回避更强。**吃对不是养生，是给改变供能**。

## 9.5 睡眠（你已在改善，关键参数）

你的发现完全正确：
- 温度 23-24℃
- 湿度 60-70%
- 控制大脑兴奋（睡前不折腾工具、不刷刺激内容）

补充几个关键点：
1. **固定起床时间**（比固定睡觉时间更重要）——稳定生物钟
2. **早晨见光**（拉开窗帘/外出10分钟）——重置昼夜节律

4. **睡前1小时不屏幕**（蓝光抑制褪黑素）——这对你最难，但最有效
5. **如果睡不着，不躺床上硬熬**——起来做无聊的事，困了再回床

你昨晚两点才睡，原因"大脑兴奋+环境温湿度"——前者靠睡前1小时不折腾解决，后者靠空调/加湿器解决（你正在推进空调更换，对）。

## 9.10 容纳反复：系统的最后一环

整个系统的最后一个原则，也是最重要的心态：**反复是规律，不是失败**。

你会在某些周做得很好，然后某天突然又回到老样子——不想打电话、不想投简历、和母亲吵架、折腾软件到深夜。这不是你"又完了"，这是改变的正常波动。

**应对反复**：
1. 不放大：一次反复≠全部失败
2. 不自责：自责消耗精力，精力是恢复的本钱
3. 看趋势：关注"两次好状态之间的间隔有没有变短"
4. 快恢复：反复后，用最小行动（2分钟法则）重启，而不是等"状态好"

你的整个改变之路，会是这样的曲线（不是直线）：

```
状态
 ↑        ╱─╲   ╱──╲  ╱───(持续上升)
 │       ╱   ╲ ╱    ╲╱
 │     ╱      ╳
 │   ╱      ╱ ╲
 │ ╱      ╱    ╲
 └────────────────────→ 时间
   反复  反复  反复（但每次恢复更快、峰值更高）
```

**允许反复，但每次恢复得更快一点。这就是成功。**
