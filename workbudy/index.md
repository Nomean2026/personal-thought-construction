# 自我改善教程 · 主页

> 从专业心理学与辩证唯物主义双重视角，分析你这套"程序"的成因与运行机制，
> 以"理解道理 → 剖析原因 → 落实方法"的循序渐进逻辑，带你完成内在统一与持续改变。

---

## 教程定位

不是给你一堆"道理"，而是让你：
1. **看清楚**自己这套"程序"是怎么写出来的（成因）
2. **看懂**它现在为什么这样运行（机制）
3. **能动手**改写它（实践方法）
4. **能持续**维护它（生活系统）

## 教学三段式（每章统一遵循）

```
① 理解道理（What） → 这一章讲的现象与原理是什么
② 剖析原因（Why）  → 它在你身上为什么这样形成、这样强化
③ 落实方法（How）  → 切实、简单、可执行的改变步骤
```

## 理论基底

- **辩证唯物主义**：客观环境是主要的，主观能动性是启动器；事物是发展变化的、相互影响的。
- **心理学**：依恋理论、原生家庭理论、神经可塑性、认知行为疗法（CBT）、接纳承诺疗法（ACT）、习惯回路、自我决定理论。
- **实践框架**：学—抄—做三阶段（神经重塑 = 学习）。

## 教程总原则

> 你的核心洞察是对的：**最管用的是行动，只有通过一次次行动的正向反馈才能客观改善，但也可能反复。**
> 本教程的所有方法，都服务于一个目标：**降低行动门槛，增加正反馈，接纳反复，持续向前。**

## 立即开始

从第一章开始，按顺序阅读。每章末尾都有一个2-5分钟的"章末行动"，请务必做——改变不是看完教程发生的，是做完行动发生的。

**你已经开始了。** 你今天打的那通公租房电话，就是这套教程的第一个实证：你比你自己以为的，更有能力改变。
