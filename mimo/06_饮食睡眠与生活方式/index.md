## 第二节：睡眠的科学管理

### 2.1 睡眠周期与睡眠卫生

一个完整的睡眠周期包括：
- <strong>NREM 1期</strong>：浅睡期（1-5分钟）
- <strong>NREM 2期</strong>：轻睡期（20-25分钟）
- <strong>NREM 3期</strong>：深睡期（20-25分钟）
- <strong>REM期</strong>：快速眼动期（做梦期，20-25分钟）

每晚需要4-6个完整周期，即7-9小时。

### 2.2 环境因素对睡眠的影响

你提到发现了一个重要信息："温度在 23℃-24℃、湿度在 60%-70% 时，更容易入睡"。这与研究一致。

#### 最佳睡眠环境

| 因素 | 最佳范围 | 你的发现 |
|------|---------|---------|
| <strong>温度</strong> | 18-24℃ | 23-24℃ ✓ |
| <strong>湿度</strong> | 40-70% | 60-70% ✓ |
| <strong>噪音</strong> | 低于30分贝 | 临近路很吵 ✗ |
| <strong>光线</strong> | 完全黑暗 | 没法关灯 ✗ |
| <strong>床品</strong> | 舒适透气 | — |

#### 你的环境改善方案

由于公租房的噪音和灯光问题暂时无法改变，可以采取以下措施：

1. <strong>降噪耳塞</strong>：有效降低环境噪音
2. <strong>眼罩</strong>：遮挡光线
3. <strong>白噪音</strong>：用手机播放白噪音掩盖环境噪音
4. <strong>空调调节</strong>：虽然空调有问题，但尽量调到合适温度

### 2.3 失眠的认知行为疗法（CBT-I）

<span class="tooltip">CBT-I<span class="tip-text">失眠的认知行为疗法（Cognitive Behavioral Therapy for Insomnia）：治疗失眠的首选方法，比安眠药更有效且无副作用。核心包括：睡眠限制、刺激控制、认知重构和睡眠卫生教育。</span></span>是治疗失眠的首选方法，比安眠药更有效。

#### 核心技术

1. <strong>睡眠限制</strong>：
   - 只在真正困的时候上床
   - 如果20分钟睡不着，起来做点放松的事
   - 困了再回去

2. <strong>刺激控制</strong>：
   - 床只用来睡觉（不看手机、不工作）
   - 每天固定时间起床（包括周末）
   - 不要在床上"躺着等睡着"

3. <strong>认知重构</strong>：
   - 不要担心"睡不够怎么办"
   - 不要数时间"已经过了多久还没睡着"
   - 接受"今晚可能睡不好"，反而更容易睡着

## 第三节：整体生活方式设计

### 3.1 运动、社交、休闲的平衡

你提到"每天留时间给第一种事情（想做的事）"，这很重要。

#### 每日生活结构建议

```
早上（6:30-8:00）：
  - 起床、洗漱
  - 简单运动（散步/拉伸）
  - 健康早餐

上午（8:00-12:00）：
  - 处理"不得不做的事"（打电话、请假）
  - 或"认为要做的事"（学习、工作）

中午（12:00-14:00）：
  - 午餐（注意营养搭配）
  - 短暂休息（20-30分钟午睡）

下午（14:00-18:00）：
  - 继续"认为要做的事"
  - 或外出活动（试驾、见朋友）

晚上（18:00-22:00）：
  - 晚餐
  - "想做的事"（打球、看电影、放松）
  - 和朋友相处

睡前（22:00-23:00）：
  - 放松活动（阅读、听音乐）
  - 避免使用电子设备
  - 准备入睡
```

### 3.2 满足自己的欲望

你提到"今天明天想去试驾一辆车，就应该去"。这是一个很好的想法。

#### 为什么满足欲望很重要？

1. <strong>多巴胺奖励</strong>：满足欲望会释放多巴胺，让你感到快乐
2. <strong>掌控感</strong>：做自己想做的事，增强对生活的掌控感
3. <strong>平衡</strong>：只有"应该做"的事，生活会变得枯燥

#### 操作原则

- 每天至少做一件"想做的事"
- 每周至少一次"奖励自己"的活动
- 不要把"想做的事"排到最后

### 3.3 从"逼自己"到"照顾自己"

你提到"每天把自己逼到图书馆去学习、总结"。但"逼"不是长久之计。

#### 转变思维

| "逼自己" | "照顾自己" |
|---------|-----------|
| 我必须去学习 | 我选择去学习，因为这对我的未来有帮助 |
| 我不能休息 | 我需要休息，这样我才能更好地学习 |
| 我不应该浪费时间 | 我允许自己放松，这是必要的 |

#### 实践方法

1. <strong>自我对话</strong>：用"我选择"代替"我必须"
2. <strong>自我奖励</strong>：完成任务后，给自己一个小奖励
3. <strong>自我接纳</strong>：做不到也没关系，明天继续
